1・2Museを入れて、コードを入力する

ステップ1　Museのアプリを入れる

Museは、AIのお手伝いさんの名前です。まず、このアプリをスマートフォンに入れます。

iPhoneをお使いの方

  1. ホーム画面で「App Store」という、青いアイコンを押します
  2. 画面の下、または上の「検索」を押します
  3. 「Muse」と入力して検索します
  4. 「Muse」のアプリが表示されたら、「入手」を押します
  5. インストールが終わったら、「開く」を押します
  6. 画面の案内に沿って、参加の手続きを進めてください

Androidをお使いの方

  1. ホーム画面で「Play ストア」という、カラフルな三角のアイコンを押します
  2. 画面の上の検索欄を押します
  3. 「Muse」と入力して検索します
  4. 「Muse」のアプリが表示されたら、「インストール」を押します
  5. インストールが終わったら、「開く」を押します
  6. 画面の案内に沿って、参加の手続きを進めてください
途中で分からなくなったら、その画面のままで止めてください。LINEで玉川にご連絡いただければ、その場面から一緒に確認します。

ステップ2　招待コードを入力する

参加の手続きが終わったら、招待コードを入力します。このコードは、玉川が以前LINEでお送りしたものです。LINEのトーク画面をさかのぼると見つかります。

大切な決まりが1つあります。コードの入力は、参加してから48時間以内にお願いします。時間が過ぎると入力できなくなります。参加したら、その流れで入力まで済ませてください。
  1. Museのアプリを開きます
  2. 「設定」を開きます（スマートフォン本体の設定ではなく、Museのアプリの中にある「設定」です）
  3. 設定の中の「Redeem token」という項目を押します（英語ですが、意味は「コードを入力する場所」です）
  4. LINEでお送りしたコードを、そのまま入力します
  5. 確認のボタンを押して、完了です

入力がうまくいかないときは、無理に何度も試さなくて大丈夫です。その画面の写真（スクリーンショット）を撮って、LINEで玉川にお送りください。

3・4WhatsAppを入れて、つなぐ

ステップ3　WhatsAppを入れる

WhatsAppは、LINEと同じようなメッセージのアプリです。海外では多くの方が使っています。

このアプリを入れる理由は1つです。WhatsAppから、自分のMuseに話しかけられるようになるからです。声で伝えることも、写真を送ることも、文書のファイルを送ることもできます。

iPhoneをお使いの方

  1. 「App Store」を開きます
  2. 「WhatsApp」と入力して検索します
  3. 「WhatsApp Messenger」を「入手」します
  4. 開いて、画面の案内に沿って登録を進めます

Androidをお使いの方

  1. 「Play ストア」を開きます
  2. 「WhatsApp」と入力して検索します
  3. 「WhatsApp Messenger」を「インストール」します
  4. 開いて、画面の案内に沿って登録を進めます
登録の途中では電話番号を入力します。すると、確認の番号が届きます。その番号は、ご本人の確認のためのものです。他の人に教えず、ご自分で入力してください。

「How to Use Whatsapp - Beginner's Guide」（Howfinity／約10分・200万回以上見られている動画）
英語の動画ですが、登録から、メッセージ・写真・通話までの画面の動きがよく分かります。言葉が分からなくても、画面の様子を見るだけでも参考になります。実際の操作は、このページの日本語の手順に沿って進めてください。

ステップ4　MuseとWhatsAppをつなぐ

アプリが2つ入ったら、最後につなぐ作業をします。操作はMuseのアプリの中で行います。

  1. Museのアプリを開きます
  2. 「設定」を開きます
  3. 設定の中の「Messaging channels」という項目を押します（英語ですが、意味は「つなぐメッセージアプリを選ぶ場所」です）
  4. 「WhatsApp」を選びます
  5. 画面の案内に沿って進めると、接続が完了します

接続が終わると、WhatsAppの中に、Museとのトーク画面が現れます。試しに、ひと言送ってみてください。

試しに送る ひとこと
「こんにちは」

返事が来れば、準備は完了です。音声で送りたいときは、トーク画面のマイクのボタンを。写真や文書を送りたいときは、クリップのような形のボタンから選べます。

5・6さっそく練習してみましょう

ステップ5　練習1　録音から議事録を作る

会議の録音を渡して、議事録を作ってもらいます。Wordで作ったような、きちんとした形に整えることもお願いできます。

  1. 会議を録音します（スマートフォンの録音アプリで大丈夫です）
  2. 手書きのメモがあれば、写真に撮ります
  3. WhatsAppの、Museとのトーク画面を開きます
  4. 録音のファイルを送ります
  5. メモの写真も送ります
  6. 下のお願いの文章を送ります
お願いの文章の例　そのまま写してお使いください
この録音から、議事録を作ってください。
日時、参加者、話し合ったこと、決まったこと、次にやることを、分けて書いてください。
Wordで作ったような形に整えてください。

出来上がったら内容を確認してください。直してほしいところは、そのまま伝えれば大丈夫です。「参加者の名前が違います」「この部分を、もう少し短くしてください」など、言い直せば何度でも直してくれます。

見本にしたい議事録がある場合は、その写真やファイルも一緒に送って、「この形で作ってください」と添えてください。

ステップ6　練習2　教科書で会話の練習をする

NHKラジオ講座の教科書を使って、会話の練習をします。

  1. 教科書の、練習したいページを開きます
  2. そのページの写真を撮るか、スクリーンショットを撮ります
  3. WhatsAppの、Museとのトーク画面を開きます
  4. その写真を送ります
  5. 下のお願いの文章を送ります
お願いの文章の例　そのまま写してお使いください
このページの内容で、先生役になって、会話の練習をしてください。
私が質問したら、答えてください。
答えは、やさしい言葉でお願いします。
  • 質問は、日本語でも大丈夫です
  • 分からない単語があれば、「これはどういう意味ですか」と聞いてください
  • もう一度聞きたいときは、「もう一度お願いします」と伝えてください

練習は、好きなときに始められて、好きなときに終われます。時間を気にする必要はありません。

  • パスワードは、エージェントにも、誰にも、教えないでください。パスワードを聞かれる場面があっても、教える必要はありません

この決まりがあるので、安心してお試しいただけます。
