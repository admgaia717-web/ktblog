N v1: お箸の手をあごの下まで上げて /n/。M と同じ作り方です。

北浦先生のご指示（11/5 15:04）で作った N の1本目です。左右反転、カードを持つ手は下ろして体の横、もう一方の手は人差し指と中指をそろえたお箸の形で、/n/ のたびにお腹の前からあごの下まで上げて下ろします。名前 → /n/ ×3 の10秒です。Nancy は手が下にある時に2本の指に半透明で重ね、手が上がると透明にしました。
