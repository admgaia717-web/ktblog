## 北浦先生改善点（2026-09-07・KT経由で受領）
1. 動きはアクション基本・説明部分はなくてOK
2. 説明時は人間が手のひらにキャラを乗せて静止
3. アクション時はキャラ半透明（手の動きを邪魔しない）
4. 説明とアクションは分離検討（練習時にくどい）
5. 発音の声はMarkである必要はない（声変わりの違和感回避）
6. リンゴはフルーツそのものではなくキャラクターで表現
