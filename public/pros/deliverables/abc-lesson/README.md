# プロス ABC まねっこレッスン

カード・提供音声・先生の実演を組み合わせる対面レッスンです。発音・動作・授業採用は先生の確認をお願いします。

## 開いて使う

ダッシュボードの「教材を開く」から始めてください。保存版はZIPを展開し、フォルダを丸ごと保ったまま `index.html` をブラウザで開きます。スマホではダッシュボードの教材URLをご利用ください。スマホ実機での音声再生は未確認のため、授業前に使う端末でABCの音を確かめてください。

1. a・b・cを選び、「おはなし」を先生が読みます。
2. 「音をきく」で提供音を確認し、先生が口と手の動きを見せます。
3. 「いっしょにまねる」で練習します。1・3・5回と、返す間2・4・6秒を選べます。「abc つづけて」は各文字を選んだ回数ずつ再生します。
4. 「もういっかい」でくり返し、「できたね」で終えます。停止・文字変更・画面切替で再生を中止できます。

「1回」は提供WAV全長を1回再生する意味です。提供音は今回の制作・配布で長さ・速度・高さ・音量・前後の余白を変更していません。提供前の音量加工履歴は `manifest.json` に記載しています。

## 印刷と先生用ガイド

- `print/cards.pdf`：ABCカード、A4横1枚。
- `print/teacher-guide.pdf`：先生用手引き、A4縦1枚。
- 同名のHTMLからも印刷できます。A4・倍率100%・余白なし・ヘッダーとフッターなしで指定し、プリンターの印字可能範囲を確認してください。実紙印刷は未確認です。

画面の「先生用ガイド」に動作・進行例・素材の採否があります。現在の標準はカード＋提供音＋先生実演です。生成動画は口元の重なり、動作と音の対応、正本意匠などに課題があり、採用していません。

## 評価・修正を伝える

先生用ガイドの欄に「文字／お話・音・動作・見え方／直したい一言」を入力してコピーし、いつもの連絡方法でお渡しください。自動送信はされません。児童名は書かず、再読込前にコピーしてください。
