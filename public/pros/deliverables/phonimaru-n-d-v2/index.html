N Nancy Noodle d-v2（10秒）

腕なしの下地に、pi N v1 の Wan の腕（左手・横向き）を不透明で重ねました。顔・体・服は下地のまま。口は /n/ の間だけ n_2 に替えます。

10.0秒 / 24fps / 1920×1080 / AAC。mp4 の sha256 は af36fd3b32f1e90f。

直した点

腕なしの下地元の絵から動かす腕と手を消し、服と背景を描いた下地（n_base_1）を先に作りました。元の腕の跡はありません。
不透明で重ねる下地に、Wan の腕と手を肩から指先まで 100% 不透明で重ねました。半透明にしていません。
袖上の腕はシャツの青に戻しました。袖口はそのまま。ぼかしは輪郭の1pxだけです。
最初と最後手がお腹にあるコマも、下地＋Wan の腕で作りました。元の腕は使っていません。
顔・体下地のまま固定。鼻先の動きは x 1.52px・y 2.41px。
口/n/ の間だけ、閉じた口 → n_2 → 閉じた口。約0.3秒でゆっくり変えます。パカパカ切り替えません。
Nancy手がお腹にある最初と最後だけ。胸〜あごでは出しません。

機械検査

顔240/240 検出。pitch 幅 5.17°、yaw 1.85°、roll 2.65°、鼻先 x 1.52px・y 2.41px。
手240/240 検出（2手）。手の上下の幅 129.30px。3.0〜3.6秒は同じ高さで止まっています。
音名前 0.452〜1.234秒。 /n/ 2.988〜3.919 / 5.488〜6.419 / 7.988〜8.919秒。
原寸3.2秒（あご下）・4.6秒（胸）を原寸で確認。腕の向こうに服や元の腕は透けていません。
