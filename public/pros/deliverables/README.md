## 使い方

1. **ウォームアップ（5分）** — 本文 Warm-up の3問をペアで議論。
2. **画像提示** — img-01 を見せて「Where is she? What is she doing?」など予測させる。
3. **会話（10分）** — まず mp3 を1回通しで聴かせる → 本文でペア読練 → その後 img-02 を見せて Part 2 を同様に。
4. **語彙（10分）** — 12語表の意味確認 → 表を隠してクイズ。
5. **文法（10分）** — 3パターンの入れ替えドリル。よくある誤り「You like a drink?」（Would 抜け）を丁寧に矯正。
6. **練習（8分）** — Exercise A〜C。解答と解説は本文の「Answers & Explanations」。
7. **まとめ（5分）** — 店員役と客役のロールプレイ。

詳細な時間配分は本文末尾「Notes for Teachers」を参照。
