N Nancy Noodle d-v1（10秒・試作）

名前 → /n/ ×3。手はお腹の前のお箸の形から、あごの下まで上げて下ろします。Nancy は手が下にある間だけ、2本の指に重ねます。声・カード・口の形は N v3 と同じ素材です。

10.0秒 / 24fps / 1920×1080 / AAC。mp4 の sha256 は 5300726e8f2b792f。

作り方

生成FAL alibaba/wan-3.0/image-to-video、1080p・3秒。はじめの絵を左右反転して生成し、戻す。腕を上げて下ろす動きを1回作る。
構成2.5〜4.75 / 5.0〜7.25 / 7.5〜9.75 秒に、上げ→あご下→下ろすを3回。名前 2.0秒、/n/ 3.0・5.5・8.0秒。
全身生成体・頭も Wan の出力をそのまま使う。顔を止めて腕だけを貼る方法ではない。
合成カード・名前・n 表示・Nancy・/n/ の口を、N v3 と同じ位置に合成。
費用1080p 3秒 ×2 $1.20 ＋ 口の絵の編集 ×2 $0.30 ＋ 720p 3秒テスト $0.30 ＝ $1.80（上限 $2.50）。

機械検査

顔240/240 検出。pitch 幅 8.26°、yaw 4.63°、roll 2.59°、鼻先 x 25.84px・y 23.31px。
手236/240 検出（2手）。手の上下の幅 219.55px。
音名前 0.452〜1.234秒。 /n/ 2.988〜3.919 / 5.488〜6.419 / 7.988〜8.919秒。
二重全身を同じコマから使うため、体・手の二重は見えません（3.2・5.7・8.2秒で確認）。
シャツ色手の切り貼りをしていないため、腕にシャツの色は付いていません。

残っている点（試作）

  • 手があごの下に来た時、指が下くちびるの一部に重なります。口と歯は指の上に出ています。
  • 顔が動きます（pitch 幅 8.26°、鼻先 25.8px）。pi 版 v3 は顔を1コマに固定しています。
  • 生成された顔のあごが、少し長く見えます。
  • 指はあごの下で縦向きです。先生の n_2 は横向きです。
  • 先生の確認前。採用版ではありません。
