作成：フォニ丸pi（右の D 版の作成はフォニ丸D）

N：どれで進めるか選んでください

N Nancy Noodle /n/ の候補を並べました。左と中央はフォニ丸pi の2通り（A・B）、右はフォニ丸D の版です。動画を見比べて、どれで進めるかを教えてください。

pi 版 A（N v4-A・M v28 と同じ作り方）

作成：フォニ丸pi

10秒・名前 → /n/ ×3 · v4 のページ

作り方

  • 顔・体・服は元の静止画のまま止める
  • 動画からは腕と手だけを、手の形ぎりぎりのマスクで重ねる
  • /n/ の間だけ口を n_2 の形に替え、約0.3秒かけてなめらかに開閉

残っている課題

  • 腕の付け根のまわりで、動画の腕と止めた服の境目が見えるコマがあるかもしれない
  • 動いている途中、指の境目が少し浅く見えるコマがある

pi 版 B（N v4-B・v3 をもとに）

作成：フォニ丸pi

10秒・名前 → /n/ ×3 · v4 のページ

作り方

  • v3 と同じく、手が動く間は動画の体を使う
  • 口のまわりだけ元の絵と n_2 の口に戻す
  • 腕に付いたシャツの青を、腕の肌の色にそろえる

残っている課題

  • 顔は動画どおりわずかに動くので、口のまわりの境目が見えるコマがあるかもしれない
  • 動いている途中、指の境目が少し浅く見えるコマがある

D 版（N d-v1・試作）

作成：フォニ丸D

10秒・名前 → /n/ ×3 · D 版のページ

作り方

  • 動画AI（FAL Wan 3.0）で腕を上げて下ろす動きを作り、体・頭も動画のまま使う（顔を止めて腕だけ貼る方法ではない）
  • カード・名前・Nancy・/n/ の口は pi 版 v3 と同じ位置に合成

良い点（D 版ページより）

  • 全身を同じコマから使うので、体・手の二重が出にくい
  • 手の切り貼りをしないので、腕にシャツの色が付かない

残っている課題（D 版ページより）

  • 手があごの下に来た時、指が下くちびるの一部に重なる
  • 顔が動く。生成された顔のあごが少し長く見える
  • 指はあごの下で縦向き（先生の n_2 は横向き）
どれが良いか教えてください。気になる所があれば、版の名前と秒数でお知らせください。
