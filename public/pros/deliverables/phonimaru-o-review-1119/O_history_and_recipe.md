### 遠回りになった理由（4つ）
1. **原因を見る前に直し方を重ねた**: v18〜v22 は継ぎ目を1つずつ塞ぐ直しを重ね、試す回数が増えた。v23 以降は「原因のコマを4倍で見て、方法を1つに決めて1回で作る」に変えて、ほぼ1回で直るようになった。
2. **自動で縁を探すのに頼った**: 指の下の縁・口の線を色の差で自動で探すと、似た色（指の影とほお）で見誤った。人の目で読むか、AI に一体で描かせる方が早かった。
3. **元の動画を確かめなかった**: v1 で 30fps の Wan を「同じコマの2回見せ」でのばしていたこと、元の fr85 で指が2本に割れていることを、v21 まで知らなかった。
4. **道具の生死を確かめずに見積もった**: fal のページに載っていても、VACE・LTX inpaint の窓口は廃止済みだった。
5. **数字でなめらかでも、人の目では違う**: v28 は手首・ひじの移動量はなめらかだったが、RIFE で作った中間の絵で指が崩れていた（数字では分からない）。v29 のしわは理屈どおり口角と一緒に動いたが、人には「不気味」に見えた。**合成した絵は全コマ4倍で目で見る。顔の部品は「理屈で正しい動き」より「見慣れた止めた絵」に近い方が自然に見える。**

## 2. 次に同じ質にする最短手順（目安：半日）

### 0. 先に確かめる（15分）
1. 元の Wan の動画の fps とコマ数、v1 での「のばし方」（2回見せがあるか）を表にする。
2. 元のコマを 4倍で並べ、指が割れている・二重のコマに印をつける（使わない）。
3. fal で使う道具の窓口が生きているか確かめる（ページではなく実際の窓口。空の注文は受け付けて動くことがあるので、確かめ方に注意）。

### 1. 腕と手（1時間）
1. 2回見せのコマは、RIFE 4.25（scotty の `.venv`、`v21/tools/rife_arm.py`）で前後の真ん中の絵に替える。指が二重になるコマは元のまま。
2. 手のマスクは、差の閾値で取った形を **15px 閉じて埋める**（`v23/work/arm_layer23.py`）。指が頬と似た色の所で抜けるのを防ぐ。
3. 赤線の内側の帯は、シャツの上のシャツだけなじませる。肌（赤>青+20）と、背景から 4px 以内の輪郭はそのまま（`v18/work/arm_layer22.py`）。
4. 動き出し（止めた絵の手→動画の手）から指が口に着くまでは、キーのコマ（止めた絵の手、腕のコマ 30、47〜58）の手の位置の道のりを出し、smoothstep で全コマに割り当てて、間を RIFE で作る（`v28/work/compose_o28.py`）。
5. **指が一気に大きく回る組（元のコマ 51→53）は RIFE で作らない**。本物のコマを使い、その1歩だけ大きくなるのは許す（`v29/work/compose_o29.py` の RETIME の上書き）。作った中間の絵は、全コマを4倍で並べて指が崩れていないか見る。

### 2. 口（1時間）
1. O の絵を、鼻の位相相関で C に合わせる（0.1px 以下）。
2. 口の線は 8倍＋5px 方眼で読み、口角と、線がうすい所は 16倍で読み直す。
3. 口角は C→O へ t に合わせて横にも動かす。口の中は O の絵だけを使う。
4. 口の箱は縦8倍で描いて、8行ずつの面積平均で戻す（`v20/work/mouth_o19.py` の `render4`）。
5. 開ききりの高さを前の版にそろえる（MS で調整）。
6. 笑った口角のしわは、そのコマの絵で測った濃さ（まわりのほおより暗い分）だけを元の所から消し、口角の動きぶんずらして足す（`v28/work/assemble28.py` の③）。指のまわり 10px は測らない（指の下の影を動かさない）。**しわを口角に付けて大きく動かす（v29）と不気味に見えるので、v28 の程度にとどめる。**

### 3. 指が口に来る所（30分＋AI 1回）
1. 指先より左の「動画の唇・頬のかたまり」は、口の絵で埋める（`compose_o21` の ZONEFIX）。指の影の肌は削らない。
2. 指の下のくぼみは、自動で縁を探さない。ほおと指のまわりを切り出して、FLUX.3 Edit Video（fal、720p で 0.03ドル/秒）で1回描き直す。くぼみの所だけをぼかしたマスクで貼り戻す（`v26/work/flux_paste.py`）。
3. 2回目・3回目は同じ絵の所なので、同じ直しを流用する（差6以下の画素だけ、`flux_copy23.py`）。

### 4. 確かめ（30分）
1. 部分ごとの「前のコマとの差」を v17 と並べた表（どこが新しく跳ぶか）。
2. 名前の区間の差0、直した範囲の外の差0（数字）。
3. 4倍で、口・指・肩・ほおの主なコマを前の版と横並びにして目で見る。
4. 通常の速さの比較動画を作り、最後は人の目で決める（Claude は動画を再生して見られない）。

- ktblog の検討ページ（一覧に載せない）に、比較動画と「直したこと・残ること」を載せる。変更履歴に1件。push 後に認証つきで開いて確かめる。
