# 【加藤ラジコン #98】$60で作る四足歩行ロボット——オープンソース「Sesame」が変える個人メカトロの景色

2026年、ロボット工学はかつてないほど手近になった。かつては大学の研究室か、軍事予算のある某所でなければ触れることのできなかった四足歩行ロボット。その技術が、今、50ドルの箱から這い出している。

タイトルの「Sesame（ごま塩）」。名前の由来は単純だ。安価で、身近で、日常に溶け込む。そんな意味を込めて、開発者のDorian Toddはこの小さな四足機械に名前をつけた。

GitHubで3,500スター以上を獲得し、485フォーク。APACHE 2.0ライセンスで全CADデータ、ファームウェア、ドキュメントが公開されている。3Dプリンタがあれば、Arduino IDEが使えれば、基本的なはんだ付けができれば——世界で最も安い四足歩行ロボットが、あなたの手の上に現れる。

本稿では、Sesameの技術的詳細を掘り下げつつ、同時代の類似プロジェクトと比較し、個人メカトロ愛好者にとってこの波が何を意味するのかを検証する。

## Sesameの誕生——なぜ今、安価な四足ロボットなのか

2025年11月、GitHubに「dorianborian/sesame-robot」というリポジトリが出現した。それから半年足らずで、スター数は3,500を突破した。Discordコミュニティでは、世界中のメーカーズが組み立て過程を共有し、改良提案が飛び交っている。

ロボット工学の世界では、四足歩行は「正解のない問題」として知られている。二足歩行が複雑なのは当然として、四足ですら、安定歩行を実現するには逆運動学（Inverse Kinematics）、ガイトパターン生成、IMUセンサーによる姿勢制御、そしてリアルタイムのサーボ制御が必要だ。

では、なぜSesameは「8個のSG90サーボ」だけで歩けるのか。

答えは「簡潔な設計哲学」にあった。

Sesameは完全な逆運動学ベースの歩行制御を採用していない。代わりに、事前計算されたガイトパターンを再生する。各脚は2自由度（前後スイング＋上下リフト）で、8個のサーボが協調して、対角歩法（trot gait）を実現する。

対角歩法とは、左前脚と右後脚が同時に前進し、次に右前脚と左後脚が前進する歩法。哺乳類の犬や猫が自然に使う歩法だ。Sesameはこのパターンを単純なサーボ角度のシーケンスとして記録し、再生する。

これはMIT Mini Cheetahのような研究用ロボットとは根本的に異なるアプローチだ。Mini Cheetahは12自由度の腿部、力制御モータ、IMUセンサー融合によるリアルタイムバランス制御を備えている。コストは数百万円。対するSesameは、位置制御サーボとパターン再生。安価であるがゆえに、学習者にとって理解しやすい。

## ハードウェア構成——ESP32 S2 Miniがすべてを制す

Sesameの心臓部は、Espressif SystemsのESP32 S2 Mini。240MHzデュアルコアプロセッサ、Wi-Fi内蔵、512KB SRAM。この小さなチップが、8個のサーボ制御、OLED表示、Wi-Fi通信、REST APIサーバーを同時にこなす。

## ファームウェア——Arduino IDEで書けるC++

SesameのファームウェアはC++で記述され、Arduino IDEでコンパイル・書き込み可能だ。リポジトリには「base firmware」と「expanded firmware」の2種類が用意されている。

```cpp
// 基本的なサーボ制御の例
#include <Servo.h>

Servo leg_servos[8];
int leg_pins[] = {2, 3, 4, 5, 6, 7, 8, 9};

void setup() {
  for (int i = 0; i < 8; i++) {
    leg_servos[i].attach(leg_pins[i]);
  }
}

void trot_cycle() {
  // 対角歩法: 左前+右後、右前+左後
  leg_servos[0].write(90);  // 左前_上前
  leg_servos[5].write(90);  // 右後_下前
  delay(300);
  leg_servos[1].write(45);  // 左前_下前
  leg_servos[4].write(45);  // 右後_上前
  delay(300);
  
  leg_servos[2].write(90);  // 右前_上前
  leg_servos[7].write(90);  // 左後_下前
  delay(300);
  leg_servos[3].write(45);  // 右前_下前
  leg_servos[6].write(45);  // 左後_上前
  delay(300);
}
```

## ソフトウェアエコシステム——Sesame StudioとCompanion App

Sesameの妙味は、ハードウェアだけではない。ソフトウェアエコシステムが充実している。

### Sesame Studio

アニメーション構成ソフトウェア。Pythonで動作し、ブラウザベースのUIを提供。サーボのキーフレームを視覚的に配置し、リアルタイムでプレビュー可能。

### REST API

JSON APIにより、Python、JavaScript、その他の言語からプログラム制御が可能。

```python
import requests

SESAME_IP = "192.168.1.100"

# 歩行アニメーション再生
requests.get(f"http://{SESAME_IP}/api/animate/walk")

# 特定のサーボを制御
requests.post(f"http://{SESAME_IP}/api/servo", json={
    "id": 0,
    "angle": 90
})
```

## OLEDディスプレイ——ロボットに「顔」を与える

Sesameの特徴的な要素の一つが、128×64ピクセルのOLEDディスプレイ。ファームウェアに組み込まれた表情ライブラリは、happy、sad、surprise、angry、talk、sleepなどのパターンをサポート。
