## 第1段階：建設ペースこそが今のボトルネック——ノキアCEOの「2倍」発言が示すもの

AIデータセンターをめぐる需要の強さを示す発言として、ノキアCEOの言葉は象徴的です。同CEOは、供給制約がなければAIデータセンターの建設は現在の2倍のペースで進んだはずだと述べています。需要と資金が潤沢にあるのに建設がそのペースに届いていない。つまり、足を踏み絞めているのは需要側ではなく、供給側、とりわけ建設のスピードだという診断が、この発言の核心にあります。

注目すべきは、制約の所在が変わった点です。かつては「需要があるか」「資金を調達できるか」「チップを確保できるか」が論点の中心でした。ところが今の段階では、それらがそろったとしても、実際にデータセンターを立ち上げられる速度が追いつかず、拡張全体の上限を規定しつつあります。ボトルネックが計画や投資の段階から、建設という実行の段階へ移ったことは、AIインフラをめぐる議論の質を変える出来事です。

実際、データセンターブームは続いていますが、個々のプロジェクトは増大する障害に直面していると報じられています。需要が明確に存在するのに建設が阻害されている——これは一時的な調整ではなく、構造的な制約が働いている証左と見るべきでしょう。

言い換えれば、AI計算資源の将来像を語るうえで、半導体の性能やモデルの進化だけでは不十分です。それらを物理的に「置く場所」として立ち上げられる速さ、すなわち建設ペースが、産業全体の律速段階になりつつあります。ノキアCEOの「2倍」発言は、需要側の熱量がすでに供給側の限界を上回っていることを示す目安です。次に問われるのは、その建設ペースを何が、どのように遅らせているのかという点です。

## 第2段階：需要があるのに建てられない——制約が次の制約を呼ぶ連鎖の仕組み

第2段階で注目したいのは、需要そのものは明らかに存在しているのに、供給が追いつかないという構造です。ノキアCEOが「供給制約がなければ2倍のペースで建設できた」と述べたことは、事業者側に建てたい意志と資金があるにもかかわらず、現実の建設速度がそれに届いていないことを示しています。つまり問題は「需要がない」のではなく「建てられない」ことにあります。

なぜ建てられないのか。ここには制約が次の制約を呼ぶ連鎖が働いていると考えられます。建設を加速しようとすれば、まず土地や電力の確保が壁になります。電力を確保しようとすれば、送電網や変電設備の増強が追いつかず、さらにその設備を作る機材や人手が不足する。一つの工程を無理に早めれば、次の工程に負担が回り、全体としては速くならない。これが典型的な律速の連鎖です。

Bainが「彼らが来るなら建てられるのか（Can We Build It If They Come?）」という問いを投げているのも、まさにこの点を突いています。顧客であるAI事業者が実際にやって来るとして、その需要を受け止めるだけの建設能力が供給側に備わっているのか、という問いかけです。データセンターブームが続く一方で、プロジェクトは増大する障害に直面しており、需要と供給の間に埋まらない溝が生まれています。

この段階で重要なのは、ボトルネックが単一の資源ではなく、複数の制約が時間差で顔を出すことです。電力が解決されたプロジェクトでも、次は資材や施工力が詰まる。制約は消えるのではなく、場所を移しながら連鎖していくのです。

## 第3段階：現場を直撃する障害——「Can We Build It If They Come?」が突きつける問い

本節で扱うのは、AIデータセンター建設の現場に直撃する障害である。Bainはこのブームに対して「彼らが来るなら建てられるのか（Can We Build It If They Come?）」という問いを投げた。この問いの本質は、需要側の話ではないということだ。データセンターブームが続き、来るべき需要は見えている。それでも建てられるかどうかは、別次元の問題として立ちはだかる。

前段までに見たとおり、ノキアCEOは「供給制約がなければ2倍のペースで建設できる」と述べた。つまり潜在能力と実際のペースの間には差があり、その差を埋める工程そのものが、いま障害にさらされている。Bainの問いは、まさにこの工程を突き、「来る需要」を前提にしたとき、その受け皿を現実に構築できるのかを問うている。

ここで注意すべきは、資料が示す「プロジェクトは増大する障害に直面する」という事実である。障害は一つではなく、増大しながらプロジェクトを直撃する。制約連鎖の考え方でいえば、上流で解消された制約は、下流のより細い制約にボトルネックを移す。建設ペースという律速段階が意識された今、障害はさらに現場寄り、つまり着工から竣工までの各工程に集中して現れると見るのが自然だ。

「彼らが来るなら」という表現には、需要は確かだが供給側の応答が追いつくかという危うさが込められている。来ることが確実でも、受け皿を建てる速度が伴わなければ、ブームは能力不足のまま過ぎていく。Bainの問いは修辞ではなく、現場を直撃する障害の存在を前提にした、実務的な警鐘として読むべきだろう。

## 第4段階：供給網のどこが次に詰まるのか——拡張速度を律速する候補の検討

AIデータセンターの拡張ペースを考えるとき、注目すべきは「供給網のどこが次に詰まるのか」という問いです。ノキアCEOが「供給制約がなければ2倍のペースで建設できる」と述べ、Bainが「彼らが来るなら建てられるのか」と問いを投げているいま、ボトルネックは単一ではなく、拡張の速度そのものを律速する複数の候補として姿を現しつつあります。需要は明らかに存在するのに、供給の側がその速度に追いつけるかが問われている段階にあるわけです。

制約連鎖の考え方では、一つの制約が解消されると、次は前段では不足していなかった資源が相対的に細くなります。建設ペースが上がれば、資材や機材の調達、拠点となる土地や既存設備の確保、電力系統との接続など、これまで個別には目立たなかった項目が連続して律速候補として浮上します。重要なのは、これらが独立した問題ではなく、どこか一か所が遅れると全体の竣工がそこに揃えて遅れるという点です。ベルトコンベアの速度が最も遅い工程で決まるのと同じ構造であり、供給網のどこに最も遅い工程があるかを特定することが、拡張速度の見通しを左右します。

データセンターブームが続く一方で、プロジェクトが増大する障害に直面しているという事実は、特定の一社や一部門の努力だけでは解消できないことを示唆します。したがって実務的には、供給網全体を流れとして捉え、どの資源が次の不足に転じるかを先回りで棚卸しする提案が有益だと考えます。読者の皆さんも、自社の調達や投資判断のなかで、次の律速候補を点検する視点を持つことをすすめたいと思います。

## 第5段階：読者が制約連鎖から読み取るべきこと——投資と調達の視点をどう変えるか

建設ペースが律速要因になると分かったとき、投資家と調達担当者はどこを見るべきでしょうか。筆者の見立てを述べるなら、視点の置き所は「需要の強さ」から「拡張の速度」へ移すことだと思います。

ノキアCEOが「供給制約がなければ2倍のペースで建設できた」と述べ、Bainが「彼らが来るなら建てられるのか」と問いを投げた。この二つの発言が共通して示すのは、AIデータセンターの成長を左右するのが需要側ではなく供給側だという事実です。データセンターブームが続く一方で、プロジェクトは増大する障害に直面しています。ここから読み取れるのは、計画の発表や受注の数字だけを追っていても、律速する建設の実勢速度を見誤るというリスクです。

投資の視点としては、計画された規模ではなく、実際に建設が進む速度が上振れ・下振れの分岐点になると考えるのが自然です。建設が想定より遅れれば、供給の拡大も遅れ、需要と供給の時間差が生じます。この時間差がどこに価格や優先順位の形で現れるかを追うことが、従来の需要予測中心の見方に代わる軸になるのではないでしょうか。

調達の視点では、増大する障害が供給網のどこで表面化するかを前倒しで把握する姿勢が求められます。障害は一度に現れず、制約が次の制約を呼ぶ形で連鎖します。だからこそ、調達側は納期や能力の遅延を個別事象としてではなく、連鎖の一環として捉え、計画に遅延の読み込みを組み込むことを提案したいと思います。

要するに、制約連鎖の時代には「建てられるのか」という問いへの答えを自らで追跡することが、投資と調達の両方に共通する前提になると考えるのが妥当でしょう。
