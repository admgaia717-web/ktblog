# 頭・首・身体をバラバラに持て——AI時代に「自分」を失わないための設計思想
### OpenAIやAnthropicに全部預けたら、あなたの判断力は誰のものになる？

---

## 1. AIに全部任せることが「怖い」本当の理由

「AIに仕事を任せたら便利だよね」と言うのは簡単だ。

でも、考えてみてほしい。

もし**モデル（頭脳）も、プロバイダ（通信路）も、ハーネス（道具立て）も、全部一つの会社のもの**だったら？

OpenAIが全部握っている。Anthropicが全部握っている。グーグルが全部握っている。

あなたは「AIを使っている」つもりで、実は**その会社のルール・価値観・制限の中でしか考えられない状態**にされる。

これは**思考のアウトソーシング**だ。便利だけど、あなたの「自我」は少しずつ奪われる。

> **比喩：**
> 料理を作るとき、食材（モデル）も、仕入先（プロバイダ）も、レシピ本と調理器具（ハーネス）も、全部「マクドナルド」からしか選べなかったら？
>
> あなたはマクドナルドの社員が決めたメニューしか作れなくなる。「自分はハンバーガーが好き」と思っていても、それ以外を食べたことがないから、それが「自分の好み」だと錯覚する。

これが、今まさにAI業界で起きていることだ。

---

## 2. 縦型統合の罠——一社に握られると何が起きるか

2025〜2026年、各社はこういう戦略を取っている：

| 会社 | モデル | プロバイダ | ハーネス | 結果 |
|------|--------|-----------|---------|------|
| **OpenAI** | GPT-5 / Codex | OpenAI API | Codex CLI | 全部自社。乗り換え困難 |
| **Anthropic** | Claude 4 | Anthropic API | Claude Code | 全部自社。プロンプト非公開 |
| **Google** | Gemini 3.1 | Gemini API | Gemini CLI | 全部自社。ただしApache 2.0でOSS化 |

これがなぜ問題か。

### 2-1. あなたの「判断」がフィルタリングされる

Claude Codeのシステムプロンプトは**非公開**だ。何を指示されているか、ユーザーにはわからない。

Anthropicは「安全性」の名の下に、モデルが答えてはいけないことを決めている。その判断基準は**ブラックボックス**。

OpenAIも同じ。Codex CLIのRust製ハーネスは公開されているが、モデル自体は完全なプロプライエタリ。

つまり：
- あなたが見えている「AIの答え」は、ある会社の**倫理基準・ビジネス戦略・政治的な判断**でフィルタリングされたもの
- そのフィルタリングは**見えない**
- あなたは「自分の判断」だと思って、実は**誰かの判断をなぞっている**

### 2-2. 乗り換えコストが天井知らず——搾取の構造

全部を一社に依存すると、乗り換えたくても乗り換えられない。

- ハーネスが自社モデルにしか対応していない
- 会話履歴がエクスポートできない
- プロンプトの微調整ができない

これが意味することは一つ：**相手が値上げしても、あなたには従う以外の選択肢がない。**

### 価格の罠：年間10万円が突然20万円になる現実

2026年現在、すでにこういうことが起きている：

| 会社 | 2025年料金（月額） | 2026年料金（月額） | 実質的な値上げ率 |
|------|-----------------|-----------------|---------------|
| Anthropic Claude Code Pro | $20 | $100（Max実質必須） | **5倍** |
| OpenAI ChatGPT Plus | $20 | $20（Codex CLIは込み） | 維持 |
| Google Gemini CLI | 無料 | 無料〜（制限強化） | 実質減 |

Anthropicの例が象徴的だ。$20/月のProプランでは「数回の複雑なプロンプトで上限到達」する設計になっている。実用的に使うには$100/月のMaxプランが必要——これが**事実上の5倍値上げ**だ。

しかも、すでにClaude Codeのワークフローに慣れてしまったユーザーは：
- 「Anthropicしか使えないハーネス」に依存している
- 「$100高いけど…」と渋々支払う
- 不満でも乗り換え先がない

これが**ベンダーロックインによる搾取**の構造だ。最初は安く見せかけて、依存させてから刈り取る。

> **比喩：**
> 最初は「月々たったの$20で最新AI使い放題！」という広告。
> 3ヶ月後には「通常プランでは上限に達しました。Proプランは月$100です」と言われる。
> あなたはすでにこのAIなしでは仕事が回らなくなっている。**支払うしかない。**

これは偶然ではない。**設計された搾取構造**だ。

### 2-3. 「便利」の向こう側

「でも便利だからいいじゃん」という意見もある。

確かに、全部同じ会社の製品を揃えると、設定も連携もスムーズだ。Apple製品のような体験。

でも、Appleの場合は「ハードウェアを買う」だけだ。あなたの**考え方**までは支配されない。

AIの場合は違う。**モデル（思考そのもの）を相手から借りている状態**で、しかもその思考回路を自分で点検できない。

---

## 3. 対抗手段：3層をバラバラに持つ

では、どうすればいいのか。

答えはシンプルだ。**頭（モデル）・首（プロバイダ）・身体（ハーネス）を、それぞれ別の選択肢から選べる状態を維持する。**

```
【悪い例】                  【良い例】
OpenAI 一社に全部依存       → モデル：自由に選ぶ
                            → プロバイダ：OpenRouter / OpenCode
                            → ハーネス：Pi / OpenCode
```

![](/assets/eyecatch/harness_architecture.png)

### 各層の独立性の意味

| 層 | 分離して持つ意味 | 具体的选择肢 |
|---|----------------|------------|
| **モデル（頭）** | 思考のフィルタリングを避けられる。複数モデルを使い分けられる。 | DeepSeek / Qwen / Kimi / Claude / GPT / ローカルモデル |
| **プロバイダ（首）** | 価格競争の恩恵を受けられる。地域制限を回避できる。一社が落ちても他で動く。 | OpenRouter / OpenCode Go / OpenClaw / 直接API |
| **ハーネス（身体）** | システムプロンプトを読める・編集できる。透明性を確保できる。 | Pi（200トークン） / OpenCode（OSS） / Aider |

---

## 4. 具体的な「分離の習慣」

高校生でも今すぐできる分離の習慣を紹介する。

### レベル1：モデルを複数持つ（初級）

最低でも2つの異なる会社のモデルを使えるようにしておく。

```bash
# Piなら設定ファイル1つでモデル切り替え
~/.pi/agent/settings.json に providers を複数登録

# 例：Claude + DeepSeek + ローカルモデル
```

「Claudeが落ちた」「GPTが遅い」というときに、もう一つで動かせる。**これだけで依存度が劇的に下がる。**

### レベル2：プロバイダを中間に挟む（中級）

直接APIを叩かず、OpenRouterやOpenCode Goのような**マルチプロバイダ**を経由する。

```bash
# 直接Anthropic APIを叩かない
# → OpenRouter経由でClaudeもGPTもQwenも同じインターフェースで使う
```

これにより：
- 一社のAPI障害で止まらない
- モデル間の価格競争を自動利用できる
- 設定変更だけでモデルを差し替えられる

### レベル3：ハーネスはOS Sで透明なものを選ぶ（上級）

システムプロンプトが読めて、編集できるハーネスを使う。

| ハーネス | プロンプトの透明性 | 編集可能性 |
|---------|-----------------|-----------|
| **Pi** | ✅ 完全公開（200〜1Kトークン） | ✅ 自由に編集可 |
| **OpenCode** | ✅ モデル系統別8種類を公開 | ✅ 上書き可 |
| **Aider** | ✅ 公開 | ✅ 自由 |
| Claude Code | ❌ 非公開（逆解析のみ） | ❌ 不可 |
| Codex CLI | ⚠️ ハーネスはOSS、モデルは非公開 | ⚠️ 部分的 |

**「あなたのAIがどんな指示で動いているか、あなたが読めない」という状態は、自我を預けたも同然だ。**

---

## 5. で、結局どれを選べばいいの？

この記事の結論は「Claude Codeが悪でPiが善」ではない。

大事なのは **「分離して持つ習慣」** だ。

| 状態 | あなたの自由度数 |
|------|---------------|
| 全部Claude Code + Anthropic | 🔴 低い（一社依存） |
| 全部Codex CLI + OpenAI | 🔴 低い（一社依存） |
| Pi + OpenRouter（複数モデル） | 🟢 高い |
| OpenCode（BYOK）+ 複数プロバイダ | 🟢 高い |
| ローカルLLM + Pi | 🟢 最高（完全独立） |

理想的な状態はこうだ：

```
メイン：OpenRouter + Claude（品質重視のタスク）
サブ：OpenRouter + DeepSeek V4 Flash（コスト重視）
予備：ローカルLLM + Pi（オフライン・機密タスク）
非常用：別のハーネス + 別のプロバイダ（障害時）
```

**「一つの選択肢」ではなく「選択肢のセット」を持つ。**

これがAI時代に自我を保つための、最も実践的な戦略だ。

---

## 6. まとめ：選択肢を武器にしよう

```
AIに全部を任せたとき、あなたは二つのものを失う：
　1. 「違う答え」を知る機会
　2. 自分で判断しているという感覚
```

ハーネスを分ける。プロバイダを分ける。モデルを分ける。

これは単なる技術的なベストプラクティスではない。**AI時代に、あなたの思考をあなたのものとして維持するための、最も基本的な自己防衛手段**だ。

高校生のあなたに伝えたい：

「このAI、便利だな」と思ったときこそ、一度立ち止まってほしい。

- このAIの「頭脳」は誰のもの？
- このAIの「指示」は誰が書いたもの？
- このAIの「答え」は、他のAIでも同じ？

そして、その全部が同じ会社のものだったなら——**その会社の都合で、あなたの考え方が quietly に作られていく**ことを自覚してほしい。

テクノロジーは使うものだ。使われるものではない。

その一歩が、**頭・首・身体をバラバラに持つ**という選択だ。

### 一番かわいそうなのは、搾取されていることに気づかないこと

この記事を読んでいるあなたは、もう大丈夫だ。

でも、世の中には：
- Claude Codeしか知らないから「月$100が普通」だと思っている人
- ChatGPT Plusで「月$20なら安い」と喜んで、知らない間に学習データに自分の仕事を提供している人
- Gemini CLIの無料枠に慣れて、使い続けるうちにGoogleのエコシステムに完全に組み込まれていく人

が大勢いる。

彼らは**搾取されている**。でも、それに気づいていない。

- 高い金を払わされているのに、それ以外の選択肢を知らない
- 「便利だから」という理由で、自分の判断力を少しずつ手放している
- 抗う方法がわからない

一番かわいそうなのは、**搾取されていることに気づかないこと**だ。

この記事があなたに伝えたいことは：

1. **頭・首・身体を分離して持つ習慣をつけよう**
2. **複数の選択肢を常にキープしよう**
3. **システムプロンプトが読めないツールには依存しないほうがいい**
4. **値上げされたら即座に乗り換える準備をしておこう**

これらは全部、無料または格安で実現できる。PiもOpenCodeもAiderも無料だ。OpenRouterの登録も無料だ。ローカルLLMを動かす環境も、一度整えればランニングコストは電気代だけ。

**守るべきはあなたの判断力であり、あなたの財布だ。**
そしてその両方を守る方法は、もうあなたは知っている。
