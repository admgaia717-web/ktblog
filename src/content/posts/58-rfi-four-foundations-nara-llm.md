【58】RFI締切3日前——大学・技術・実践・継承、四つの基盤がすべて動き出した

**⚠️ 奈良市RFIの締切は2026年7月3日（金）。あと3日。**

これまで57本の研究ノートで追いかけてきた「ならしLLM」構想。その輪郭は徐々に明確になってきたが、今日の4つの研究エントリは特に重要な意味を持つ。なぜなら——教育基盤、技術基盤、実践基盤、文化継承基盤の**四つすべてが同時に動き出した**からだ。

それぞれが独立した研究トピックに見えて、実は同じ地点を指している。奈良でAIを教える、という北極星の下で。

## 一、教育——人を育てる基盤

奈良女子大学・NAIST周辺の教育プログラムが、2026年前半に大きく動いた。

**WE Program 2026夏季**は応募受付を終了したが、特筆すべきは企業サポーターの拡大だ。JR東海（東海旅客鉄道）が新規参入。鉄道業界からのWE Program参加は初めて。TJ Systems（東芝情報システム）も継続参画。重工・半導体・鉄道と業種の幅が広がっており、プロスのiWAM（人材アセスメント）という独自ツールとの差別化余地は広がっている。

**NAIST STELLA第4期生**の募集は本日6月30日が締切。大学院生メンター制度が確立し、博士後期課程のメンター2名が特別講義を実施した実績がある。KTのNAIST進学後にメンターとして参入するルートは、制度として明確に機能している。

**Lab4SLC（須藤克仁研究室）**はM2が7名と設立以来最大規模。2027年3月に7名が修了後、M1 2名＋B4 3名の小規模体制になる。KTが2027年春にNAISTから接続するタイミングと、Lab4SLCの新規学生獲得サイクルが合致する可能性がある。

そして**工学専攻（修士課程）**が2026年4月に新設され、初年度を順調に稼働中。情報エリアの中核教員・吉田哲也教授（機械学習・データサイエンス）の研究テーマは、つるまいデータ分析と完全に重複する。

```
現実味を帯びた参入ルート：
  プロス講師 → WE Program企業サポーター参画
  NAIST進学 → STELLAメンター → Lab4SLC連携
  → 奈良女子大・工学専攻での非常勤講師
```

## 二、技術——作る基盤

2026年前半、地域特化LLMを「実験室から実用へ」引き上げる技術的基盤が一気に揃った。

**SwiReasoning（ICLR 2026採録）**は、LLMの推論において明示的Chain-of-Thoughtと潜在空間推論を動的に切り替える訓練不要フレームワーク。平均精度1.8-3.1%向上、トークン効率57-79%向上。特に予算制約が厳しい環境ほど効果が高く、M1 Max 64GBのローカル環境との相性が極めて良い。正倉院文書解析（高難度）と市民の声要約（軽量）を同一モデルで処理できる可能性がある。

**QLoRA + DoRA**の組み合わせが2026年の実用的ベストプラクティスとして定着した。IEEEアクセス論文（DOI: 10.1109/ACCESS.2025.10903789）で、DoRAがQLoRAと組み合わせることでフルファインチューニングにかなり近い精度を達成することが確認されている。7B QLoRAならRTX 4090 1枚で2-4時間、コストはたった$1.10-2.20。

**LLaMA Factory v0.9.5**（2026-05-30リリース）はGLM-4.7-Flash SFT対応、APOLLO optimizer、Liger Kernel統合（訓練VRAMを40-60%削減）と、選択肢は豊富だ。

モデル選定では**Qwen3-14B**がQwen2.5-32B相当の性能を半分以下のVRAMで実現。GLM-4.7-Flash（Z.AI）も日本語性能が高く評価されている。

```
ならしLLM技術スタック（2026年6月版候補）：
  ベース：Qwen3-14B（本番） or Qwen3-8B（実験）
  FT手法：QLoRA + DoRA（$2でフルFT級精度）
  推論効率化：SwiReasoning（訓練不要・57-79%効率向上）
  訓練FW：LLaMA Factory v0.9.5
  推論FW：llama.cpp / MLX（Mac統一メモリ活用）
```

学習コストが「実験」の閾値を超えた。これは「作れるかどうか」ではなく「何を作るか」を考えればよい時代になったことを意味する。

## 三、実践——動かす基盤

つるまい移動支援は15ヶ月で累計894件の予約を処理。月額運用コスト1,550円。この数字は「机上の空論」ではない。

**全国のAI電話自動化事例との比較**から、つるまいの無競合ポジションが再確認された。グラファー北九州（50%AI完結率）はマイナンバーカード限定のFAQ回答。EasyDialog一関市（日本初フルスタック生成AI電話）も行政FAQが対象。**「福祉交通（デマンド/ボランティア送迎）の予約受付を音声AIで自動化する」事例はつるまい以外に存在しない。**

この「交差点」ポジションは偶然ではない。上方にAI配車最適化の大手企業群（アイシン・未来シェア・WILLER等）、下方にAI電話FAQ回答のスタートアップ群（グラファー・EasyDialog）——両者の間にはっきりとした空白があり、つるまいはそこに唯一位置する。

**奈良市DX推進課の実力**も、小平市議の行政視察レポート（2026年5月）で明らかになった。生成AIを全職員2,500名に配布、半年で17,200時間削減。管理職研修1回で利用率38%→74%。事前RFI制度化——入札前に民間から意見を募る仕組みが確立している。RFI提出先は数字で裏付けられた実績と組織的推進力を備えた先進部署である。

RFI提案書v1.3の強化ポイントも見えてきた：
- 「交通空白2,500カ所＋集中対策期間R7-R9」の国策フレームを冒頭に
- グラファー・EasyDialogとの差別化（福祉交通×音声AI予約＝無競合）を明確に
- LLM判断分離型設計を安全性の根拠として明示
- 「予約受付の100%自動化＋人間エスカレーション」を目標に（北九州市の50%を上回る）

## 四、継承——活かす基盤

文化継承×LLMの分野で、2026年6月は歴史的な月だった。

**Vesuvius Challenge**が6月25日、ヘルクラネウム巻物1本の完全解読を達成。79年のヴェスヴィオ噴火以来約2000年間、炭化パピルスは物理的に開くことができなかった。高分解能X線CT＋機械学習により、巻物を一度も開くことなく全文を読むことに初めて成功。22カラムのギリシャ語テキスト——ストア派哲学論考（紀元前2世紀）が蘇った。データ・コードは全てオープン（CCライセンス）。

この「開かれた科学」の威力は、正倉院文書のデジタル化にも直接適用できる教訓だ。

**ICOMOS Japan**に掲載された高田祐一（奈良文化財研究所）の論考は、「正確に計測し忠実に保存する」から「自動解析・意味理解・損傷予測・仮想復元・知識統合・再構築（Reconstruction）」へのパラダイムシフトを宣言する。すでに奈良文化財研究所のLLM考古学情報抽出は精度17%→90%（わずか2ヶ月で5倍以上向上）を達成している。

**みんなで翻刻**（橋本雄太・歴博）は累計5千万字超。2026年7月11日には歴博講演会「市民とAIが協力して古文書を解読」を開催。市民参加型プラットフォームとAIの協働——これはならしLLMの設計思想そのものだ。

一方で**データ主権**の議論も本格化している。Springer誌に掲載された「AIにおける先住民言語とデータ植民地主義」の批判的レビューは、コミュニティが設計を主導する場合にのみAIは搾取なく機能すると警告する。ならしLLMが「市民の声」のデータ主権を設計段階から組み込む必要性は、この国際的議論と地続きである。

## 結論：四つの基盤が交わる地点

今日の4つの研究エントリを並べると、不思議なほど明確な構造が見えてくる。

||基盤|内容|担当者・組織|
|---|---|---|---|
|一|教育|WE Program / STELLA / Lab4SLC / 工学専攻|奈良女子大・NAIST|
|二|技術|SwiReasoning / QLoRA+DoRA / Qwen3 / LLaMA Factory|グローバル研究コミュニティ|
|三|実践|つるまい894件実績 / 奈良市DX / 無競合ポジション|KT・プロス・奈良市DX推進課|
|四|継承|Vesuvius完全解読 / ICOMOS / みんなで翻刻 / データ主権|国際研究機関・奈良文化財研・歴博|

教育で人を育て、技術でものを作り、実践で動かし、文化継承に活かす。

この四つが揃ったとき、「ならしLLM」は単なる構想から**基盤を持つプロジェクト**へと変わる。そしてこの四つが同時に動き出したのが、まさにこの2026年6月である。

RFI締切まであと3日。だが、焦る必要はない。基盤は揃いつつある。今やるべきは、この四つの基盤を一本の線で結ぶこと——RFI提案書の中で。
