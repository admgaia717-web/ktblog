# 2026年 AIサブスクリプション完全比較：マックスプラン12選の使用感と実態

## はじめに

2025年後半から2026年にかけて、各社が競うように「マックスプラン」「ウルトラプラン」と称する高価格帯のAIサブスクリプションを投入している。月額100ドルを超え、中には300ドルに達するプランもある。

本記事では、Ollama Cloud Maxを皮切りに、Cursor Ultra、Claude Code Max、ChatGPT Pro、Z.AI GLM Coding Max、Perplexity Max、Grok Heavyなど11の主要プランについて、ユーザーの口コミや第三者評価をもとに使用感を比較する。各社の公式情報と実際のユーザー報告のギャップを明らかにし、最適なプラン選びの指針を提供する。

---

## Ollama Cloud Max（月額$100）

### プラン概要

Ollama CloudはローカルLLM実行環境のクラウド拡張版。Free / Pro / Maxの3階層で、Maxは月額100ドル。主な仕様は以下の通り：

- Proの5倍のGPU時間
- 最大10並列モデル
- 5時間ローリングウィンドウ＋週次リセット（7日）
- プライバシー：プロンプトや応答データを記録・学習に利用しない方針

利用可能なモデルはGLM 5.1、DeepSeek V4 Pro、Kimi K2.6など、オープンソース系の最新モデルが中心。Ollamaはモデルをネイティブウェイト（プロバイダがリリースしたそのままの重み）で提供しており、量子化は行っていない。

### メリット

**コスト効率の高さ**：毎週約12.5億トークン相当まで使えるため、月額100ドルで多種のオープンモデルにアクセスできる。Claude Max（$200）の半額でありながら、モデルの種類は豊富で、OpenClawなどのエージェントフレームワークとの親和性も高い。

**プライバシー**：Ollamaは「データ保存も学習もしない」と明記しており、競合他社と比較しても明確なスタンスを取っている。

**並列処理**：Maxプラン利用者の報告では、GLM 5.0系を用いて複数のコーディングエージェントを同時に動かしても週次使用量の10〜15%程度しか消費しないという。日常的な開発業務には十分な余裕がある。

### デメリット

**推論速度の問題**：多くのユーザーが推論速度の遅さを報告している。具体的な数値として、GLM 5で約11 tokens/s、GLM 5.1で約8 tokens/s、Qwen 3.5で約14 tokens/sといった報告がある。ただし、これらの数値はOllama Cloudの逼迫時や特定条件下での測定であり、公式API経由ではより高速（GLM 5で68.7 t/s、GLM 5.1で約52 t/s）である点に注意が必要だ。一方で50〜100 t/sの速度が出たとの報告もあり、時間帯や地域による変動が大きい。

**使用量制限の不透明さ**：2026年春頃、使用量上限が予告なしに変更されたとの報告が複数ある。具体的な計算として「1回のHermesエージェントタスク（31リクエスト）で5時間セッションの17.1%、週次使用量の3.1%を消費する」との報告があるが、これはGPU時間ベースの使用量測定であり、モデルやタスクによって消費量は大きく変わる。

**サポートと透明性**：使用量変更や遅延の告知が遅い、Discordコミュニティでの議論が放置されるなど、運営の透明性に課題を感じるユーザーが多い。

### 総合評価

複数のオープンモデルを並列で使う場合のコストパフォーマンスは魅力的だが、速度の不安定さと使用量制限の不透明さがネック。速度重視のタスクでは他社APIの併用を推奨する。

## 主要サービスマックスプラン比較

ここからは各社のマックスプランを横断的に比較する。

### Cursor Ultra（月額$200）

Cursorの最上位プラン。Proの20倍の使用量を提供し、Claude Opus 4.6やGPT-5系の大型モデルを長時間利用できる。

**メリット**：固定料金で従量課金の心配がない。複数ワークスペースで並列タスクを実行しても制限に当たらないとの声がある。

**デメリット**：トークン消費効率が悪く、同じ作業に多くのトークンを消費する傾向がある。月額200ドルでも2週間程度で上限に達するケースが報告されている。同価格帯のClaude Code MaxやChatGPT Proの方が割安で性能も上との比較が多い。

**ユーザーの声**：「出力が質の割に高価で、サブエージェントを使った長時間セッションでも期待に応えない」と評価するユーザーがいる一方、「固定料金のおかげで安心して使える」と肯定的な意見もある。全体的に評価は二分している。

### Claude Code Max（5×: 月額$100 / 20×: 月額$200）

Anthropicが提供するClaude Codeの高利用者向けプラン。Proプランの5倍または20倍の利用枠を提供する。

**5×プラン**：「週の使用量が50%を超えない」「毎日数時間の利用でも上限に達したことがない」と高評価。複数ウィンドウやサブエージェントを起動してもまず上限に達しないという。

**20×プラン**：計算量の多いタスクでは5×より早く消費するという指摘がある。また2026年春以降、5時間制限が厳しくなったとの不満も一部にあるが、LimitWatchによる追跡では直近の変更は確認されていない。

**総合評価**：コード生成の品質は業界トップクラス。5×プランはコスパと性能のバランスに優れる。

### ChatGPT Pro（5×: 月額$100 / 20×: 月額$200）

※メモ内では「ChatGPT Codex Pro」と表記されているが、公式の名称は「Pro」プランである。

OpenAIの最上位個人向けプラン。Plusの5倍または20倍のCodex利用量を提供する。

**使用枠の余裕**：最も評価が高い点。「ほぼ使い切れない」「1日8時間の開発でも5時間枠の50%を下回る」との報告が多数。モデル切替を工夫すればほぼ無制限に使えるとの声もある。

**モデル品質**：GPT-5.2や5.3は思考を要する計画フェーズに向き、5.1など低レベルモデルは軽作業向け。適切な使い分けで長時間作業でもクレジットを節約できる。Claudeと比較すると「Claudeは会話調でリポジトリ全体のコンテキスト保持に優れるが、GPTはレビューや精密なチェックが得意」との評価がある。

**総合評価**：コストパフォーマンスで最も高評価。現状ではヘビーユーザーでも枠を使い切りにくい。

### Z.AI GLM Coding Max（月額$80）

中国・智譜AI（Zhipu）の最上位プラン。Lite $10/月、Pro $30/月、Max $80/月の3階層。※メモ内では「約$160/月」とされていたが、正しくは$80/月である。

**仕様**：5時間当たり約1600プロンプト、週8000プロンプトまで利用可能。GLM-5やGLM-5.2など多言語対応の大型モデルが使える。

**課題**：消費が早いという報告が複数ある。GLM 5.2はピーク時に3倍の消費係数がかかり、すぐに上限に達する。コード生成の品質はTypeScriptで古いライブラリを幻覚するなど「ジュニアエンジニアのような振る舞い」と批判されている。また英語圏ユーザーにとっては価格に見合わないとの評価が多い。

### MiniMax Coding Plan（Plus: $20 / Max: $50 / Ultra: $120）

※メモ内では「Starter $10/月」とされていたが、実際には$10のエントリープランは存在しない。最安はPlus $20/月。

コード生成特化のプラン。モデルはMiniMax M2.1またはM2.5が中心。手頃な価格でよく知られたプランだが、競合と比較して情報が少なく、コード生成能力の詳細な評価は限定的。

### Mistral Le Chat Pro（月額$14.99）

フランスMistral AIのProプラン。Mistral Medium 3.5を中心に、1日約150件のソフト上限がある。コード生成専用モデルの利用には別途API課金が必要。プライバシー保護は明示されているが、ヘビーなコーディング用途には不向き。

### xAI SuperGrok Heavy（月額$300）

xAIの最上位プラン。Grok 4 Heavyモデルにアクセスでき、無制限のメッセージと動画生成を謳う。

**実態との乖離**：公式には「ほぼ無制限で高品質の動画生成が可能」とされるが、実際の利用者からは「12時間ごとに80本まで、720pを超えると480pに自動ダウン」との報告がある。「300ドル払って制限があるのは詐欺だ」と強く批判する声がある一方、複雑なワークフローを47分で完了したと絶賛するユーザーもおり、評価は完全に二分している。

### Google AI Ultra（5×: $100 / 20×: $200）

Geminiの最上位プラン。AI Proの5倍または20倍の利用枠を持ち、AntigravityやNotebookLM、YouTube Premium、30TBクラウドストレージが付属する。

**最大の批判**：モデル自体はGemini 3.1 Proと同じで、利用枠が増えるだけという指摘が多い。Opus 4.6のクォータが10回程度で尽きる。コーディングには不向きとの評価が大勢。付帯サービスの豊富さが唯一の差別化要因だが、AI機能そのものを目的とするユーザーには魅力が薄い。

### Perplexity Max（月額$200）

リサーチ特化型チャット検索サービスPerplexityの最上位プラン。Deep ResearchやComet（ブラウザ自動操作）、Model Council（複数モデル比較）、Computer（長時間タスク自動実行）などの独自機能を提供する。

**運営への不信感**：2026年1月、ProプランのDeep Research回数が制限された（実際には20回/月ではなく500回/日）ことで「Maxへの強制アップグレードだ」と反発が起きた。告知無しの変更が信頼を損ねている。

**機能面の評価**：Model CouncilとComputerモードは高評価で、「エリートチームが動くようだ」と絶賛するユーザーもいる。一方で利用制限が非公開であることへの懸念も強い。

### 中国勢

**Baidu Qianfan（Pro 200元/月）**：5時間当たり6000リクエストとクォータの多さが魅力。ただし429エラー（レート制限）が多発し、実質的に利用できない時間帯があるとの報告がある。格安だが信頼性に課題。

**Alibaba Qwen（Lite販売終了 / Pro $50/月）**：Liteは2026年3月で新規販売終了。Proは月$50で5時間当たり6000リクエスト。コスパ良好だが利用規約が厳格で、自動化やバッチ処理が禁止されている。

**CTCloud / Huawei Cloud MaaS**：いずれも中国大手クラウド事業者による企業向けソリューション。価格はCTCloudが9.9元〜469元程度、Huaweiが59〜799元。※Huawei Maxは月間8.8億トークン（メモ内の「880万」は誤りで正しくは8.8億）。

## まとめ

2026年現在、AIサブスクリプションは月額100〜300ドルの高価格帯に突入している。各社が競うように大容量枠を提供するが、実際のユーザー満足度はサービスによって大きく異なる。

**プラン選択の指針**：
- コード生成が中心なら：**Claude Code Max 5×** または **ChatGPT Pro 5×**
- コスパ最優先なら：**ChatGPT Pro 5×**（最も枠が余る）
- 複数オープンモデルを並列で使いたいなら：**Ollama Cloud Max**（ただし速度の不安定さを許容できる場合）
- リサーチ用途なら：**Perplexity Max**（ただし運営リスクを認識した上で）
- 動画生成が必要なら：**Grok Heavy**（ただし制限を理解した上で）
- 予算を抑えたいなら：**Cursor Pro+**（$60）や **Z.AI GLM Lite**（$10）で十分な場合も多い

複数サービスの併用が最も現実的な戦略である。2026年後半はさらに競争が激化すると予想され、各社のプラン改定や新規参入に注目が必要だ。
